# Ciro v0.9.3

全新设计的 Ciro 客户端：更清爽的界面、完整的个人菜单、项目、思考深度滑杆，以及 Windows / macOS / Linux 桌面端和 Android 移动端安装包。

## v0.9.3

- **服务器部署教程**：Docker 与 npm 两种安装方式的完整步骤、公网 HTTPS 与账户配置、升级方法（见本页下方）。
- **npm 包 `ciro-client` 命令**：现在会自动读取当前目录的 `.env`；新增 `ciro-client init` 生成配置模板，以及 `--env`、`--data`、`--version` 参数。
- `.env.example` 补充语音、图片生成与团队服务的配置项。

## v0.9.2 新功能

- **繁體中文**：界面支持简体中文 / 繁體中文 / English，跟随系统时自动识别；桌面菜单同步切换。
- **对话内查找**：Ctrl/⌘+F 高亮当前对话中的所有匹配，Enter / Shift+Enter 逐个跳转。
- **回答与提问版本**：重新生成和编辑后保留历史版本，可用 ‹ › 切换比较。
- **追问建议**：回答结束后给出 3 个可一键发送的后续问题（可在设置中关闭）。
- **强调色与字体**：翡翠绿 / 湖蓝 / 紫罗兰 / 琥珀 / 玫瑰 / 石墨六种强调色；现代无衬线、系统字体、衬线阅读体三种界面字体。
- **键盘与无障碍**：跳到输入框链接、Alt+↑/↓ 切换对话、Ctrl/⌘+Shift+O 新对话、焦点样式与屏幕阅读器标签完善。
- **桌面多窗口与置顶**：Ctrl/⌘+Shift+N 新建窗口，在新窗口中打开对话，“窗口 → 置顶”。
- **画布**：在右侧编辑文档或代码，Markdown / HTML / SVG 实时预览，让 Ciro 按要求修改，可复制与下载；代码块可直接“在画布中打开”。
- **语音对话**：全屏语音模式，说完自动发送并朗读回答（服务端 `CIRO_VOICE=on`，或使用浏览器语音能力）。
- **图片生成**：“+ → 生成图片”，结果可放大查看与下载（服务端 `CIRO_IMAGES=on`）。
- **记忆**：在消息上“记住这条信息”，Ciro 会在之后的对话中参考；可在设置中查看、编辑、关闭或清空。
- **团队**：项目可导出 / 导入分享给团队成员；配置 `CIRO_TEAM_URL` 后启用成员与共享空间。

## v0.9.1 功能

- **全新界面**：象牙白 + 翡翠绿浅色主题、中性炭黑深色主题、轨道 C 新 Logo；桌面与手机布局重新设计。
- **左下角个人菜单**：名字与头像、语言（跟随系统 / 简体中文 / English）、主题（浅色 / 深色 / 跟随系统）、个性化、账户、通知、账单、同步、快捷键、帮助、下载客户端、登录/退出。
- **思考深度滑杆**：即时 / 轻度 / 均衡 / 深入 / 极致五档，可拖动、点击或键盘调节，带动画；以 `reasoning_effort` 发送给模型（原生 CIRO 深度推理同时带时间预算）。
- **项目**：新建项目归类对话，项目指令与参考文件会随项目内对话一起发送；对话可移入/移出项目。
- **对话体验**：⌘/Ctrl+K 搜索面板、斜杠命令菜单、“+”菜单（附件 / 目标模式 / 计划模式）、拖拽与粘贴附件、编辑并重发、从任意回答创建分支、置顶、行内重命名、思考过程展示、代码块一键复制、朗读、语音输入（浏览器支持时）、回答反馈、临时对话、回到底部。
- **桌面客户端**：内置本地服务，开箱即用；菜单栏“文件 / 编辑 / 视图 / 窗口 / 帮助”随应用语言切换；在“文件 → 编辑模型连接配置”中填写模型地址。
- **Android 客户端**：内置离线界面；在“设置 → 模型设置 → 连接 Ciro 服务器”填写你的服务器地址即可使用真实模型与账户。
- **附件**：图片（自动压缩，按多模态格式发送，可点开查看大图）、PDF（本机提取文字）、文本与代码，每次最多 5 个。
- **更好的回答展示**：代码语法高亮（随主题配色）、LaTeX 数学公式、工具调用与联网搜索状态展示。
- **分享与管理**：只读分享链接、提示词库、归档与批量导出/删除、导入对话 JSON、自动生成对话标题、导出 PDF / 打印、回答完成系统通知、联网搜索开关（需服务端 `CIRO_WEB_SEARCH=on`）。
- **桌面端增强**：应用内自动更新、系统托盘、全局快捷键 Alt+Space 唤出。
- **Android 返回键**：先关闭弹窗/菜单/侧栏，再回到首页，最后退到后台，不再直接退出。
- **软件包**：Docker 镜像 `ghcr.io/kllcoco/ciro-client`，npm 包 `@kllcoco/ciro-client`（GitHub Packages）。
