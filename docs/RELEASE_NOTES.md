全新设计的 Ciro 客户端：更清爽的界面、完整的个人菜单、项目、思考深度滑杆，以及 Windows / macOS / Linux 桌面端和 Android 移动端安装包。

## v0.10.1 桌宠升级

- 桌宠改用高清分层立绘（8K 母版放大，AI 分割手臂、补全身体与头发），1200×1600 清晰显示。
- 眨眼与睡觉使用真正的闭眼立绘交叉淡化，眼睛不再被拉伸。
- 手臂独立转动：挥手、点头、摇头、鞠躬、跳跃、伸懒腰、施法（法阵旋转发光）、转圈；模型可用 `<pet action="...">` 触发。
- 呼吸、头部摆动、发梢 / 裙摆 / 耳坠摆动、视线跟随。

## v0.10.0 多用户

- 第一个账户是服务器所有者：只有所有者能发布公告、管理用户、使用工作台、融合工作台、插件和账单；普通用户看不到这些入口。
- 设置 → 用户管理（仅所有者）：生成邀请码、停用 / 恢复 / 删除用户。
- 新部署模式 `CIRO_DEPLOYMENT_MODE=multi-user`；单人服务器升级后数据自动迁移，登录状态不变。
- 黑金新主题与新 logo（保留轨道 C，缺口处换成立绘里的四角星）；应用图标、启动画面同步更新。
- Q 版 Ciro 桌宠（默认关闭，设置 → 外观与背景 开启）：桌面版是可拖到任意位置的透明置顶小窗，网页版和 Android 版悬浮在应用里。
  点击、摸头、连戳、拖动、双击提问、长时间不理会睡着；Ciro 回答时一起思考；模型可以通过 `<pet>` 标签让她做表情、说话。详见 docs/PET.md。
- 为官方服务器预留默认地址（`CIRO_OFFICIAL_SERVER`，设置后 Android 版首次打开可一键连接）。

## v0.9.9 修复

- **Android“检查更新”误报“检查网络”**：之前直接调用 GitHub API，国内很多用户共用出口 IP，很容易被 GitHub 限制查询次数。现在依次通过所连接的 Ciro 服务器（共享缓存）、App 自己读取发布页、GitHub API 三种方式检查，任一成功即可；失败时会说明真实原因。（0.9.8 需要手动安装一次 0.9.9，之后即可在应用内更新。）
- **公告**：所有用户都在 设置 → 其他 → 公告 查看全部公告（首页关掉的也在这里）；发布编辑器只有服务器所有者能看到，普通用户看不到。

## v0.9.8 新功能

- **应用内更新**：
  - **Android**：打开应用后自动检查新版本，顶部提示“发现新版本”，点“更新”即在后台下载、下载完直接安装，聊天记录和设置都保留；第一次需要按提示允许 Ciro 安装应用。设置 → 关于 Ciro 也能手动“检查更新”。（从 v0.9.8 开始生效：0.9.7 及更早的 Android 版需要手动装一次 0.9.8。）
  - **电脑版**：已有应用内自动更新（Windows 安装版、Linux AppImage 可一键更新并重启；Mac 版因未做苹果签名，会打开下载页）。设置 → 关于 Ciro 可手动检查。
  - **网页版 / 服务器**：服务器升级后，打开的页面会提示刷新。
- **保留历史版本，可随时回滚**：从 v0.9.8 起的每个版本都会保留在 Releases 页面（更早的版本已移除）。新版如果有问题，可以下载上一个版本的安装包装回去：电脑版直接覆盖安装即可；Android 系统不允许直接装旧版本，需要先卸载再安装，卸载会清掉手机上的本地数据，建议先在 设置 → 文件与存储 导出完整备份（登录账户并开启同步的话，数据在服务器上，不受影响）。
- **公告推送（不用发版也能推送）**：服务器所有者在 设置 → 其他 → 公告 发布。填写标题、内容、按钮和链接，可选推送平台和起止时间，发布后已安装的网页版、桌面版、Android 版首页会直接出现这条公告（如新套餐、限时优惠、维护通知），用户可关闭。另外也支持中心公告源（`CIRO_ANNOUNCEMENTS_URL`，默认读取本项目的 `announcements.json`），让所有安装都能收到。

## v0.9.7 新功能

- **API 控制台（卖 API）**：设置 → 账户 → API 控制台。服务器提供与 OpenAI Chat Completions 兼容的接口 `/v1/chat/completions`、`/v1/models`，用这里创建的 API 密钥调用（支持流式输出，OpenAI 官方 SDK 改个 Base URL 即可）。页面里有 Base URL、curl / Python / JavaScript 示例、每个密钥今天和近 30 天的 CWU 用量与 14 天走势、最近调用记录（只记时间、模型、状态、耗时和用量，不保存内容），以及在线调试。需要服务器开启账户。
- **文件问答带出处**：除了 PDF，现在还能读 Word（.docx）、Excel（.xlsx）、PowerPoint（.pptx），都在本机读取。回答会标注出处（第几页 / 哪张工作表 / 第几张幻灯片），回答下方的“出处”可以点开，直接看到原文核对。
- **联网搜索来源卡片**：开启联网搜索后，回答下方显示参考网页的标题、网站和摘要，点开就是原网页（兼容 OpenAI 引用、citations、search_results 等常见格式）。
- **定时任务结果通知**：定时任务到点需要批准、完成或失败时，发系统通知（电脑和手机都支持；Ciro 需要处于打开或后台运行状态），点通知打开定时任务页面。同时修复了定时任务“批准后无法运行”的问题。
- **桌面版快速提问**：在任何界面按 Ctrl+Shift+Space（Mac 为 ⌘⇧Space）弹出小窗口；复制的文字会自动作为引用带进来，可以直接问“翻译一下”“解释一下”。回答会存进历史，可一键到主窗口继续。
- **手机按住说话**：按住输入框右侧的语音按钮说话，松开发送，上滑取消；轻点仍是全屏语音对话。（Android 版需要服务器开启语音识别 `CIRO_VOICE=on`。）
- **分享为图片**：回答下方“分享为图片”，或手机右上角“⋯ → 生成分享图片”，把问答生成一张排版好的图片，可保存、复制或直接分享到其他 App。
- **审查问题修复（13 项）**：插件任务“查看结果”直接显示在任务下方；切换语言后插件列表不再变空；点插件卡片自动滚到详情；搜索无结果有提示和“清除筛选”；账单 / 应用 / 技能页加载失败后可以正常重试；“隐私与安全”说明与实际一致；首次打开时首页直接引导连接模型（Android 可在首页填服务器地址）；英文界面不再夹杂中文；协作空间去掉重复标题；融合工作台按服务器真实能力显示“可用 / 部分可用 / 未连接”；按钮对键盘和读屏更友好；小字号和浅色文字更易读；Esc 可关闭模型菜单，平板上画布不再被侧栏遮住，手机上对话菜单不再被截断。

## v0.9.6 体验优化与修复

- **设置重新设计**：手机上先显示分组列表（常用 / 数据与同步 / 账户 / 工作台与扩展 / 其他），点进去是单独页面，左上角返回、从屏幕左边缘右滑或系统返回键都能回到列表，不再需要横向翻 25 个标签；电脑上左侧导航更紧凑，并新增“搜索设置”。未开启账户时，不再重复列出 7 个内容相同的“账户尚未启用”页面；去掉重复的页面标题，文字更大更易读。
- **手机顶栏更简洁**：分享、导出 PDF、导出 Markdown、在对话中查找收进右上角“⋯”菜单。
- **触屏设备**不再显示无用的键盘快捷键提示；电脑上协作空间等页面内容居中，不再挤在左边。

- **“回答完成时通知”打不开**：Android 版改用系统原生通知（Android 13 及以上会弹出通知权限请求；之前关闭过的会直接跳到通知设置），点通知直接打开对应对话；浏览器在权限被拒绝、非 HTTPS 网址或不支持通知时，会在开关下方说明原因和解决办法，不再“点了没反应”。电脑版窗口不在前台（被其他窗口挡住）时也会提醒。
- 手机刚启动时侧滑可能卡住半开的问题。

## v0.9.5 新功能

- **工作模式（远程控制电脑）**：协作空间 → 工作模式。人在外面也能用手机指挥家里或公司的电脑：
  - **加入账号**：在电脑上的 Ciro 登录账号（密码只用一次、不保存），或在手机上点“添加电脑”拿到 8 位配对码再填到电脑上。同一账号的设备都能看到这台电脑。
  - **连接后才能下指令**：电脑上会显示二维码和 8 位配对码（约 2 分钟刷新、只能用一次）。手机点“扫码连接”扫码，或用手机相机直接扫、或输入配对码，二选一，连接后才能下指令；电脑上能看到已连接的手机并随时断开。
  - **命令**：直接运行终端命令，输出实时传回，可继续输入。
  - **AI 任务**：描述目标，电脑上的 Ciro 自己读写文件、运行命令完成任务；写文件和运行命令默认需要你在手机上批准，也可选择自动批准；显示本次消耗的 CWU。
  - 安全：只能访问电脑上手动允许的文件夹；电脑上可随时暂停或退出；服务器只保存设备密钥的哈希；需要服务器开启账户。
- **自动记忆**：Ciro 会从对话中总结你的长期偏好和背景写入记忆（不记录密码、证件等敏感信息），每次写入都可撤销，可在设置中关闭。
- **手机手势与细节**：右滑打开侧栏、左滑关闭（侧栏跟随手指）；面板下滑关闭；长按对话弹出菜单；手机键盘回车换行；轻触震动反馈；按压反馈；点击顶栏回到顶部。
- **更顺滑的启动**：Android 启动画面与应用同色，Logo 淡出后首页内容依次浮现，不再闪白。
- **对话显示**：附件以文件卡片显示（不再把文件内容塞进气泡），很长的消息自动折叠。
- **修复**：手机上各工作台页面白屏；页面顶部被手机状态栏遮挡；思考深度滑杆超出屏幕；去掉输入框下方的建议胶囊。新增 6 种屏幕尺寸的“无超出屏幕”自动检查。
- **发布页**：安装包按平台分组（Windows / macOS / Linux / Android / 服务器部署），每次只保留最新版本。

## v0.9.4 新功能

- **跨设备同步**：登录同一账户后，对话、项目、提示词和设置在电脑、手机、网页间自动同步；逐条增量加密同步，删除也会同步，两边改了同一对话以最后修改为准。默认开启，可在“跨设备同步”中关闭。
- **完整备份与恢复**：设置 → 文件与存储 → 导出完整备份，一个文件包含对话、项目、提示词、记忆、设置、图片原图和自定义背景；恢复时可选“合并”或“覆盖此设备”。
- **代码直接运行**：代码块右上角“运行”。Python 在浏览器内运行（内置 Pyodide，离线可用；numpy、matplotlib 等按需从 CDN 加载，图表直接显示），JavaScript 在隔离沙箱中运行，HTML / SVG 可直接预览。
- **Android 系统分享**：在其他 App 选中文字、链接或图片 → 分享 → “问 Ciro”，自动新建对话并填好内容；网页安装版（PWA）同样支持分享文字和链接。
- **用量统计（CWU）**：每条回答显示本次消耗的 CWU / GWU；设置 → 用量统计，可查看今天、近 7 天和近 30 天的用量、14 天趋势，以及按模型、按用途、按对话的明细。只统计模型服务实际上报的原生计量，不按 token 估算。
- **多模型对比**：“+ → 对比模型”，同一个问题同时问 2–3 个模型并排显示（含各自的 CWU 和耗时），选用一个后，其余答案保留为可切换的版本。
- **新版本提示**：服务器升级后，已打开的网页右下角会提示“Ciro 已更新”，点击刷新即可。
- **手机输入框重新设计**：输入框为空时显示语音对话按钮，输入文字后变为发送；“+”菜单改为底部弹出面板；去掉手机上的免责说明行；输入字号 16px，避免 iPhone 自动放大。
- **一键部署**：Release 附件 `install.sh`，在 Linux 服务器上一条命令完成安装；填写域名时会自动配置 HTTPS 与账户，`install.sh upgrade` 一键升级。

- **分享与管理**：只读分享链接、提示词库、归档与批量导出/删除、导入对话 JSON、自动生成对话标题、导出 PDF / 打印、回答完成系统通知、联网搜索开关（需服务端 `CIRO_WEB_SEARCH=on`）。
- **桌面端增强**：应用内自动更新、系统托盘、全局快捷键 Alt+Space 唤出。
- **Android 返回键**：先关闭弹窗/菜单/侧栏，再回到首页，最后退到后台，不再直接退出。
- **软件包**：Docker 镜像 `ghcr.io/kllcoco/ciro-client`，npm 包 `@kllcoco/ciro-client`（GitHub Packages）。
