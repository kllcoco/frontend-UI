# V0.8 手动插件市场：本轮工程交付

开发分支 `feat/ciro-v08-plugin-marketplace` 基于 `feat/ciro-v08-plugin-gateway`，保留原项目和插件安全网关。

## 用户体验与安装边界

- Ciro 主左侧导航新增「插件中心」入口。
- 插件中心内部左栏显示本账户安装的插件；右栏展示插件市场、搜索、分类、详情、申请权限与安装。
- 用户必须在市场页面先点「安装插件」、阅读权限，再点「确认安装」；服务端创建绑定浏览器会话的短效安装意图，验证插件版本及权限指纹，且只允许用一次。
- 聊天或代理的工具调用不能创建安装意图：市场写接口要求浏览器会话；模型只能通过独立工具网关使用已安装、已启用且已授权的插件。
- 安装不代表 OAuth 授权。GitHub 需要独立点击连接并授权。卸载会移除本地连接和待审批请求；上游账户授权仍建议到提供方撤销。
- 当前官方开发目录包括 GitHub、Supabase、Gmail、Google Drive、Google Calendar，只有 GitHub 被标记为可安装；尚未完成实际连接的插件显示「即将开放」，不能假装安装即用。
- 暂停/启用、单用户安装持久化、卸载、权限审批和审计保留。

## 明确未完成，禁止对外宣称已商用

1. Supabase 用户级 OAuth 与 MCP 初始化/工具发现/执行/会话恢复尚未完成。
2. Chat/Agent 的模型结构化工具调用循环、工作任务持久队列仍未接好。
3. 任意第三方签名插件包的下载、可信执行沙盒与安全市场发行仍未实现。本阶段『安装』是将官方预置适配器注册到当前用户，不是下载可执行代码到客户设备。
4. 当前持久化为单进程 JSON，非生产级多用户事务库；多实例冲突和卸载过程中进行中的请求还需加强隔离与中止。
5. 没有在当前环境执行 Node 单元测试或浏览器 E2E。新测试用例已提交，但不能算验收通过。
