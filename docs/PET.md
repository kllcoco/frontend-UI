# Ciro 桌宠

- 默认关闭。在 设置 → 桌宠 打开（用户菜单、命令面板也可以）；桌面版也可以在托盘菜单里勾选“显示桌宠”。
- 桌面版：独立的透明置顶小窗，可拖到屏幕任意位置，空白处点击会穿透到下面的窗口。
- 网页版 / Android：悬浮在应用里，可拖动，位置会记住。

## 互动

| 操作 | 反应 |
| --- | --- |
| 单击 | 开心 / 爱心，说一句话 |
| 来回摸头 | 害羞 |
| 1.6 秒内连点 5 次 | 生气 |
| 拖动 | 晃荡，放下后开心 |
| 双击 | 快速提问（桌面版打开快速提问窗口，网页 / 手机聚焦输入框） |
| 右键 / 长按 | 菜单：快速提问、打开 Ciro、让她睡一会儿、隐藏桌宠 |
| 3 分钟没理她 | 睡着（Zzz），碰一下醒来 |
| Ciro 回答中 | 思考（…），回答完成后提示 |

眼睛会跟着鼠标转；按时间段打招呼；偶尔自己“工作”一会儿。

## 同步回答与进度

- 设置 → 桌宠 → 同步显示回答（默认开）：回答实时出现在她的气泡里，完成后停留一会儿，鼠标放上去不会消失，可滚动、可打开对话。应用内的桌宠只在那个对话不在屏幕上时同步（避免重复）。
- 她也会报告进度：工作模式（电脑上的每一步，以及手机端查看任务时）、后台回答（搜索、思考、写了多少字）、定时任务结果、桌面版更新下载。
- 接口：`petStream({ id, text, done })`、`petProgress({ text, percent, done, ok, attention })`（`src/lib/pet.ts`）；桌面版经 IPC 转发给桌宠窗口，Android 经 `window.CiroPet` 转发给悬浮窗；服务器端工作模式事件经 `server/activity.mjs` 进入桌面主进程。

## 贴边、大小与后台

| 操作 | 效果 |
| --- | --- |
| 拖过屏幕下边缘松手 | 只露出头，偶尔探出来张望 |
| 拖到最上面 | 倒挂，只露出头，轻轻摆动 |
| 拖过左 / 右边缘 | 歪着身子探头 |
| 躲着时点她 / 菜单“出来吧” | 跳出来 |
| 双指捏合 · 触控板缩放 · Ctrl+滚轮（桌面版直接滚轮） | 调整大小（0.5–1.6 倍） |

- 桌面版：关掉主窗口后她仍留在桌面（托盘里退出才会离开）。
- Android：应用切到后台时，她作为悬浮窗待在手机桌面上（需要“显示在其他应用上层”权限，设置 → 桌宠 → 去允许），回到应用后回到应用内。
- 自由活动：各图层持续有小幅随机动作（重心、手臂、视线、歪头），偶尔沿着底边散步。

## 模型控制

桌宠打开时，服务器会在对话里加一段固定说明，模型可以在回复末尾加一个标签：

```
<pet mood="happy">今天也辛苦啦</pet>
```

`mood` 可选 idle、happy、love、shy、angry、sad、think、work、sleep、wave、eat；`action` 可选 wave、nod、shake、bow、jump、stretch、magic、spin、lookaround、yawn、hum、doze、tidy、giggle、sparkle、peek；文字最多 20 字。应用会把标签从显示的回复里去掉，交给桌宠执行。

## 立绘与图层

`public/pet/` 里的素材全部来自 Ciro 的 Q 版全身立绘：

- 先用 Real-ESRGAN（动漫模型）放大出 8K 母版（5760×7680），再在高分辨率下处理。
- 用 AI 分层：SAM 分割出左右手臂（含袖子、手和法阵），LaMa 补全手臂下面的身体和头发，得到 `base.webp`、`armL.webp`、`armR.webp`（1200×1600，显示尺寸的 2 倍）。
- `eyes-closed.webp`：取自同一角色的闭眼立绘，只把闭眼部分移植到原图眼睛的位置（颜色匹配、羽化），alpha 标出眼睛区域。

`src/pet/LivePet.tsx` 用 WebGL 逐层绘制：底层做呼吸、头部摆动与歪头、发梢摆动、裙摆与耳坠摆动、视线跟随（整张脸平移，不拉伸眼睛）；手臂层以肩膀为轴整体转动，法阵单独旋转发光；眨眼 / 睡觉是与闭眼图层的交叉淡化，眼睛从不被拉伸。

动作：挥手、点头、摇头、鞠躬、跳跃（下蹲—腾空—落地）、伸懒腰、施法（法阵转动发光）、转圈；由点击、问候、回答完成、空闲时随机触发，模型也可以用 `<pet action="wave">` 触发。调试：`/?pet=1&mood=sleep`、`/?pet=1&action=wave`、`/?pet=1&blink=1`。

旧的单图方式（`pet.json` 里列出各状态的图片）仍然支持。
