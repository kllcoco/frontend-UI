# Ciro 桌宠

- 默认关闭。在 设置 → 外观与背景 → 桌宠 打开；桌面版也可以在托盘菜单里勾选“显示桌宠”。
- 桌面版：独立的透明置顶小窗，可拖到屏幕任意位置，空白处点击会穿透到下面的窗口。
- 网页版 / Android：悬浮在应用里，可拖动，位置会记住。

## 互动

| 操作 | 反应 |
| --- | --- |
| 单击 | 开心 / 爱心，说一句话 |
| 来回摸头 | 害羞 |
| 1.6 秒内连点 5 次 | 生气 |
| 拖动 | 晃荡，放下后开心 |
| 双击 | 快速提问（桌面版打开快速提问窗口，网页 / 手机聚焦输入框） |
| 右键 / 长按 | 菜单：快速提问、打开 Ciro、让她睡一会儿、隐藏桌宠 |
| 3 分钟没理她 | 睡着（Zzz），碰一下醒来 |
| Ciro 回答中 | 思考（…），回答完成后提示 |

眼睛会跟着鼠标转；按时间段打招呼；偶尔自己“工作”一会儿。

## 模型控制

桌宠打开时，服务器会在对话里加一段固定说明，模型可以在回复末尾加一个标签：

```
<pet mood="happy">今天也辛苦啦</pet>
```

`mood` 可选 idle、happy、love、shy、angry、sad、think、work、sleep、wave；文字最多 20 字。应用会把标签从显示的回复里去掉，交给桌宠执行。

## 换成立绘（Q 版图片）

把透明背景的 PNG（建议 512×640，人物底部贴边、居中）放进 `public/pet/`，再新建 `public/pet/pet.json`：

```json
{ "states": { "idle": "idle.png", "happy": "happy.png", "love": "love.png", "shy": "shy.png", "angry": "angry.png",
  "sad": "sad.png", "think": "think.png", "work": "work.png", "sleep": "sleep.png", "wave": "wave.png", "drag": "drag.png" } }
```

只有 `idle` 是必需的，缺少的表情会用 `idle`。有图片时自动替换内置的矢量小人，呼吸、跳跃、晃动等动作照常生效。
预览某个表情：打开 `/?pet=1&mood=shy`。
